# Panoptes M3 后端回归门记录

> 日期：2026-05-01  
> 范围：M3 本地仓储与容量物流  
> 结论：通过，可以进入 M4 优先级物流与工业链

## 1. 完成范围

- `CityState` 新增本地 `Storage`，城市成为资源位置的权威承载体。
- 资源产出和配方完成产物进入服务城市或主城仓储。
- `Player.Resources` 保留为兼容聚合视图，旧的 dev 启动资源会迁移进主城仓储。
- 配方输入改为从服务城市本地库存和道路可达城市库存扣除。
- 新增 `rules.road_base_capacity`，真实数据当前为 `2`。
- 连通城市导入资源时会发出 `resource_flowed` 事件，并通过事件写回城市间库存转移。
- 建造消耗暂时保留国家兼容库存语义；M4 再把建设需求纳入优先级物流。

## 4. 验收场景

- 断连城市不能消费其他城市仓储，配方保持 `insufficient_resources`。
- 连通城市在运量不足时低效推进，而不是全速完成。
- 资源跨城导入会产生 `resource_flowed` 审计事件。

## 5. M4 入口边界

- M3 不做政策/国策优先级。
- M3 不做多 demand 的全局 min-cost flow。
- M3 不把大臣意图纳入物流分配。
- M4 应在当前“可达库存 + 基础容量”的基础上引入 demand priority、政策 profile 和工业链短缺传播。
